# TMS 최적 배송코스 · 카카오맵

카카오맵 기반 배송경로 최적화 도구. **단일 HTML 파일**로 동작하며, 차량 1대의 단순 순회(TSP)부터
납품처별 시간창·적재용량·고정순번·운행시간 제약을 모두 반영한 다차량 배차(CVRPTW)까지
**옵션 토글만으로** 단계적으로 확장됩니다.

```
index.html                 ← 앱 본체 (자체 완결형)
tools/kakao-proxy.mjs      ← 카카오모빌리티 API CORS 프록시 (의존성 없음)
samples/sample-stops.csv   ← 샘플 납품처 15곳
docs/DESIGN.md             ← 구현계획 · 설계 문서
```

---

## 1. 빠른 시작

### ⓪ 그냥 열어보기 (설치·키 없이)

`index.html` 을 브라우저로 **더블클릭**하면 바로 동작합니다. 샘플 납품처 15곳이 들어 있어
[최적화 실행]만 누르면 됩니다.

키가 없으면 카카오 지도 타일 대신 **좌표 기반 간이 지도**가 뜹니다. 상대 위치·경로·방문 순번·
축척이 그대로 보이므로 배차 결과를 검증하는 데는 문제가 없습니다. 도로거리 호출이 막히면
배너의 **[직선거리 추정으로 실행]** 버튼으로 바로 돌릴 수 있습니다.

> 최적화 엔진·타임라인·순서표·CSV 내보내기는 모두 이 상태에서 완전히 동작합니다.
> 아래 ①~③은 **실제 카카오 지도 타일과 실제 도로거리**가 필요할 때만 하면 됩니다.

### ① 앱 띄우기

카카오맵 JS SDK는 **도메인 등록이 필요**하므로 `file://`로 직접 열면 실제 지도가 뜨지 않습니다
(간이 지도로 대체됩니다). 실제 지도를 쓰려면 로컬 웹서버로 띄우세요.

```bash
npx serve .          # → http://localhost:3000
# 또는
python3 -m http.server 3000
```

### ② 카카오 키 발급

[카카오 디벨로퍼스](https://developers.kakao.com) → 내 애플리케이션에서:

| 키 | 용도 | 설정 위치 |
|---|---|---|
| **JavaScript 키** | 지도 표시, 장소·주소 검색 | 앱 **설정 탭 → JavaScript 앱키** |
| **REST API 키** | 도로거리 길찾기 | **프록시 환경변수** (권장) 또는 앱 설정 탭 |

> **필수**: [플랫폼] → [Web]에 `http://localhost:3000` 을 등록해야 지도가 뜹니다.

### ③ 도로거리 프록시 실행

```bash
KAKAO_REST_KEY=발급받은_REST_키 node tools/kakao-proxy.mjs
# → http://localhost:8787
```

앱 **설정 탭 → 프록시 URL**에 `http://localhost:8787` 을 넣고 **[연결 테스트]** 를 누르세요.

기본값은 **로컬호스트 오리진만 허용**합니다. 사내 서버 등 다른 도메인에 배포한다면 허용 오리진을
명시하세요(쉼표로 여러 개 지정 가능).

```bash
KAKAO_REST_KEY=키 ALLOW_ORIGIN=https://tms.example.com node tools/kakao-proxy.mjs
```

> 프록시를 `ALLOW_ORIGIN=*` 로 열어두면 사용자가 열어 둔 **아무 웹페이지나** 이 프록시를 호출해
> 카카오 REST 키 쿼터를 소모할 수 있습니다. 꼭 필요한 경우에만 사용하세요.

<details>
<summary><b>왜 프록시가 필요한가요?</b></summary>

카카오모빌리티 길찾기 API(`apis-navi.kakaomobility.com`)는 서버 간 호출용이라
`Access-Control-Allow-Origin` 헤더를 내려주지 않습니다. 브라우저에서 `fetch()`로 직접 호출하면
CORS 정책에 막힙니다.

프록시는 이를 해결하는 동시에 **REST 키를 브라우저에 노출하지 않습니다**(키는 프록시 프로세스의
환경변수에만 존재). 앱에는 "브라우저 직접 호출" 모드도 있지만 대부분의 환경에서 차단됩니다.

</details>

### ④ 실행

납품처를 넣고(첫 실행 시 샘플 15곳이 자동으로 들어 있습니다) 상단 **[최적화 실행]** 을 누릅니다.

## 2. 납품처 입력 4가지 방법

| 방법 | 설명 |
|---|---|
| **장소·주소 검색** | 카카오 검색으로 좌표 자동 확보 |
| **지도에서 찍기** | 지도를 클릭해 좌표 지정, 주소는 역지오코딩 |
| **CSV·엑셀 붙여넣기** | 엑셀에서 복사(탭 구분)하거나 CSV 붙여넣기. 좌표가 없으면 주소로 자동 지오코딩 |
| **수기 입력 폼** | 물량·시간창·순번 제약까지 한 화면에서 |

CSV 헤더는 한글·영문 별칭을 자동 인식합니다 (`samples/sample-stops.csv` 참고):

```
납품처명,주소,위도,경도,중량,부피,박스,납품시작,납품종료,하역분,우선순위,고정
서울역점,서울 중구 한강대로 405,37.5547,126.9707,320,1.2,18,08:00,11:00,15,1,
상봉점,서울 중랑구 망우로 297,37.5966,127.0853,220,0.8,12,11:00,18:00,12,0,last
```

## 3. 제약조건 옵션

옵션 탭에서 켜고 끄는 것만으로 문제 유형이 바뀝니다.

| 옵션 | 내용 |
|---|---|
| **납품 가능 시간창** | 납품처별 시작·종료 시각. 지각은 위반으로 표시 |
| **적재 용량** | 차량별 중량(kg)·부피(CBM)·박스 한도 |
| **고정 순번 · 우선순위** | "반드시 첫 번째/마지막", 우선순위 역전 방지 |
| **하역시간 반영** | 납품처별 하차·검수 소요시간을 일정에 포함 |
| **차량 운행시간 한도** | 1대당 최대 운행시간 + 운행 종료시각 |
| **차고지 복귀** | 마지막 납품 후 복귀 구간까지 계산 |
| **조기 도착 시 대기 허용** | 시간창 시작 전 도착 시 대기 (끄면 위반 처리) |
| **차량 간 물량 균등화** | 특정 차량 쏠림 방지 |

**제약 처리 방식**
- `유연(soft)` — 위반에 벌점을 물리되 해를 허용. **항상 결과가 나오고**, 무엇이 얼마나 위반됐는지 보여줍니다.
- `엄격(hard)` — 위반을 늘리는 이동을 아예 배제. 제약이 빡빡하면 좋은 해를 못 찾을 수 있습니다.

### 결정론적 실행

기본값 **켜짐**. 반복 횟수를 시계가 아닌 입력값으로 고정하므로 **같은 조건·같은 시드면 항상 같은
배차**가 나옵니다. 배차 결과를 재현·검증해야 하는 실무에서는 켜 두세요. 끄면 주어진 시간을 끝까지
써서 해 품질이 조금 올라가지만, 실행할 때마다 결과가 달라집니다.

## 4. 알고리즘

```
① 거리행렬   카카오모빌리티 1:N 길찾기(30개/요청) → 실패 구간 개별 보정 → 직선거리 폴백
             + localStorage 캐시로 재최적화 시 무호출
② 초기해     Clarke-Wright Savings (용량·차량지정 인지)
③ 개선       Simulated Annealing + relocate / swap / 2-opt / or-opt / 2-opt*
④ 다듬기     개선만 수용하는 하강 탐색
⑤ 복구       고정 순번(first/last) 강제 재배치
⑥ 실경로     차량별 다중 경유지 길찾기 → 실제 도로 폴리라인
```

모든 제약은 **미터 환산 페널티**로 단일 비용에 합산됩니다. 옵션 토글이 곧 가중치 on/off이므로,
같은 엔진이 TSP부터 CVRPTW까지 커버합니다. 자세한 내용은 [`docs/DESIGN.md`](docs/DESIGN.md).

> 휴리스틱이므로 **전역 최적해를 보장하지 않습니다.** 탐색 예산을 늘리면 해 품질이 올라갑니다.
> 납품처 30곳 이상이면 8초 이상을 권장합니다.

## 5. 결과 보기

- **지도** — 차량별 색상·선패턴 경로, 방문 순번 마커, 위반 지점 경고 배지
  (앱키가 없으면 좌표 기반 **간이 지도**로 자동 대체 — 상대 위치·경로·축척 표시)
- **배송 타임라인** — 차량별 간트 차트. 이동/대기/하역 구분, 시간창 배경 밴드로 위반이 한눈에
- **배송 순서표** — 도착·출발·구간거리·누적거리·적재·위반 사유
- **CSV 내보내기** — 기사 배포용 배송 지시서 (엑셀에서 바로 열리는 UTF-8 BOM)

차량 식별색은 색각 이상 검증(OKLab ΔE, all-pairs)을 통과한 4색만 사용하고, 5대 이상은 색을 늘리는
대신 **선 패턴(실선/파선/점선)** 을 곱해 최대 12대를 구분합니다. 방문 순번 배지·범례·결과표가 항상
함께 제공되므로 색상 단독으로 의미를 전달하지 않습니다.

```bash
npm i          # playwright 설치

```

## 7. 알려진 제약

1. 카카오맵 JS SDK는 **도메인 등록 필수** — `file://` 로는 지도가 뜨지 않습니다.
2. 카카오모빌리티 1:N 길찾기의 `radius` 상한은 10km입니다. 그 밖의 구간은 개별 길찾기로 보정하고,
   그마저 실패하면 직선거리 추정치로 대체하며 **추정 구간 수를 UI에 명시**합니다.
3. 실용 상한은 **차량 12대 · 납품처 200곳 내외**입니다.
4. 라이트 테마 전용입니다 ([`docs/DESIGN.md` §6.3](docs/DESIGN.md) 참고).
5. 데이터는 브라우저 localStorage에만 저장됩니다. 공용 PC에서는 REST 키를 앱에 넣지 말고
   프록시 방식을 쓰세요. 설정 내보내기(JSON)에는 API 키가 포함되지 않습니다.
